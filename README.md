# Retail Clothing Sales Analysis Using Microsoft Excel

## Project Overview

This project analyzes retail clothing sales data using Microsoft Excel. The goal is to understand sales performance across store locations, product categories, months, and payment methods.

The project demonstrates practical Excel skills used in data analyst roles, including data cleaning, formula-based analysis, PivotTables, and chart-based reporting.

## Tools Used

- Microsoft Excel
- Excel Tables and formulas
- Data cleaning and validation
- PivotTables and PivotCharts
- Data visualization

## Business Objectives

- Calculate key sales performance indicators.
- Compare sales across store locations.
- Analyze sales by clothing category.
- Identify monthly sales patterns.
- Understand customer payment method preferences.
- Identify missing and inconsistent data.

## Project Workflow

### 1. Data Cleaning

- Reviewed the original retail sales dataset.
- Organized the data into an Excel Table.
- Cleaned and standardized sales values.
- Identified missing dates and unknown month values.
- Checked blank and zero sales values.
- Used formulas to support data validation and analysis.

### 2. Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- Total Sales
- Total Transactions
- Total Items Sold

### 3. Sales Analysis Using PivotTables

Created PivotTables and visualizations to analyze:

- Sales by Store Location
- Sales by Category
- Sales by Month
- Payment Method Breakdown

### Sales by Month

## Data Quality Observations

- 28 records had blank dates.
- 28 records had an `Unknown` month value.
- Some records had zero sales values despite populated price and quantity fields.
- Three records had blank cleaned sales values.

These issues were identified during data validation. They should be investigated before drawing final conclusions about total sales or monthly performance.
